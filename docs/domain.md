- 시세 표 `maker_gem_prices(item, tier, price, created_at)`: tier는 `ore | low | mid | high`이고 경매장 실거래가를 기록한다. 같은 아이템 시세는 계정 전체에서 공유한다. 바꿀 때마다 한 줄씩 쌓인다.
- **고정 제련비(절대 변하지 않음):** 원석 10개 → 일반 1개(조합), 일반→하급 11만, 하급 10개→중급 33만, 중급 10개→상급 55만.
- **원석 10개 → 일반 1개 조합 비용:** 가넷·자수정·아쿠아마린·에메랄드·오팔·사파이어·토파즈는 450메소, 다이아몬드는 950메소, 흑수정은 2,900메소, 힘·민첩성·행운·지혜 크리스탈류는 4,500메소다. 흑수정은 현재 메이커 대상 목록에는 없지만 향후 추가할 때 이 비용을 사용한다.
- **확률(최신 버전 대략값):**
  - 일반 제련 결과: 보석은 하급 75% · 중급 22% · 상급 3%, 크리스탈은 하급 75% · 중급 24% · 상급 1%.
  - 하급 10개→중급 성공 50%, 실패하면 하급 1개만 사라진다.
  - 중급 10개→상급 성공 25%, 실패하면 중급 1개만 사라진다.
- **등급별 적정가 계산(`tierPrices`)**: 일반 제련 100회의 총비용을 하급·중급·상급 결과물에 배분하고 승급 손익분기 관계를 함께 푼다.
  - 일반 제련 1회 비용 `C = 원석×10 + 아이템별 일반 조합비 + 11만`.
  - 중급 `M = 11×하급 L + 66만`(하급→중급 성공률 50%와 평균 실패 1회 반영).
  - 상급 `H = 13×중급 M + 220만`(중급→상급 성공률 25%와 실패 소모 반영).
  - 보석은 `100C = 75L + 22M + 3H`, 크리스탈은 `100C = 75L + 24M + H`를 만족하도록 계산한다.
  - 연립식에서 하급 가치가 0 이하이면 하급 가격과 재고는 의미 없는 것으로 표시한다. 이때 하급은 비용 배분에서 제외하고 보석은 `100C = 22M + 3H`, 크리스탈은 `100C = 24M + H`로 중급·상급 가격을 다시 계산한다.
- **상급을 얻는 세 가지 방법(`highRoutes`)**: 원석부터 제련 / 중급 사서 가공(중급 × 13개 + 220만, 성공 25% 기준 평균) / 상급 바로 구매. 가장 싼 쪽에 "최저" 배지를 붙인다.
- **중급 기준선(`midBreakEven`)**: (원석부터 제련과 상급 바로 구매 중 싼 쪽 − 220만) ÷ 13. 중급 실거래가가 이보다 싸면 사서 가공하는 게 이득이다.
  - 배경: 중급으로 상급을 만드는 성공률이 낮고 일반 제련 중에 중급이 얻어걸리기 때문에, 경매장 중급은 제작 원가보다 싸게 거래된다. 원석이 비쌀수록 중급을 사서 가공하는 쪽이 유리해진다.
- **하급 기준선(`lowBreakEven`)**: 원석부터 제련한 중급 적정가와 중급 직접구매가 중 싼 값에서 평균 제련비를 빼고 평균 하급 소모량으로 나눈다. 정확한 정수식은 `(중급 비용 − 66만) ÷ 11`이다. 하급 실거래가가 이 값 이하이면 하급을 사서 중급으로 제련하는 게 이득이다. 결과가 0 이하면 하급 구매와 재고는 의미 없는 것으로 표시한다.
- **실거래가 제작 손익(`marketCraftProfits`)**: 카드마다 일반 제련 1회 기대 손익, 하급 구매→중급 1개 평균 손익, 중급 구매→상급 1개 평균 손익을 보여준다. 일반 제련은 하급·중급·상급의 `실거래가×등장 확률` 기여액과 합계도 보여주며, 한 번에 모두 나오는 금액이 아니라 반복 제련 시 1회 평균임을 명시한다. 각 구간에 필요한 실거래가가 없으면 필요한 시세를 안내한다. 판매 수수료는 반영하지 않는다.
- 카드에서 하급·중급·상급을 누르면 계산 과정·확률 막대·비교가 애니메이션과 함께 펼쳐진다(한 카드에 하나씩).

### 현재 기준 (2026-10-08 Claude, 사용자 결정) [진술]

아래 "이전 기록"의 확보 비용·정확 목표 모델(2026-10-04~10-07)은 모두 이 기준으로 대체됐다.

- 목적: 보유 메소로 강화에 도전해 볼 만한지, 목표 공격력 무기를 바로 사는 게 나은지 판단한다.
- 모든 결과물은 판매한다. 목표 무기는 경매장에서 산다. 목표 이상이 나와도 보유하지 않는다.
- 강화 중 10%/60%를 매 단계 고르고, 기대값상 손해면 언제든 상점가로 판매한다(기존 동적 계획법 유지). 목표 T는 주문서 선택에 직접 쓰이지 않고 판매가 경계와 구매 비교에만 쓰인다.
- 노작 원가는 입력한 값만 사용한다.
- 완성 공격력 A의 판매가
  - A < T: 입력한 실판매가, 없으면 상점가.
  - A < 가장 낮은 입력 시세의 공격력: 목표 이상이어도 입력값, 없으면 상점가(2026-10-08 사용자: "가장 싼 시세보다 아래는 상점가라 입력할 필요가 없다"). 목표가 여기 해당하면 구매가도 상점가로 보고 "상점가 기준 구매가"로 표시한다.
  - 그 외 A < 포기선: 입력 필수. 비어 있으면 계산을 대기한다.
  - A ≥ 포기선: 입력값이 있으면 사용, 없으면 추정가.
  - 경매장 시세는 최소 1개 입력해야 한다.
- q(A) = 입력한 노작들 중 A 이상에 가장 쉽게 도달하는 확률(매 단계 10%/60%를 최적으로 고른 최대 확률).
- 포기선 = q(A) × N < 1인 가장 낮은 완성 공격력. N은 화면에서 정하며 기본 1,000회다.
- 추정가 = 가장 비싸게 입력된 경매장 시세 × q(그 공격력) ÷ q(포기선 공격력). 포기선 이상 미입력 공격력은 모두 이 한 값으로 고정하고(B안, 2026-10-08 사용자 "우선은 B안"), 상점가보다 낮으면 상점가로 올린다.
- 보유 메소 판단: 노작마다 따로, 보유 메소로 도전을 반복한다. 실제 지출(노작가 + 실제 사용한 주문서)을 빼고, 남은 메소가 그 노작 1회 최악 지출보다 적으면 새 도전을 시작하지 않는다. 판매 대금은 마지막에 한꺼번에 정산하며 재투자하지 않는다. (대체됨: 2026-10-09, 시뮬레이션 제거·노작 섞기 조합으로 변경 — Claude)
- 도전 횟수가 운에 따라 달라지므로 최종 메소는 몬테카를로 시뮬레이션 근사치다. 노작별 평균 최종 메소를 비교하고, 바로 구매(보유 메소 − T 구매가)와 비교한다. (대체됨: 2026-10-09, 시뮬레이션 제거·노작 섞기 조합으로 변경 — Claude)
- 보유 메소 판단 (2026-10-09 Claude, 사용자 결정): 시뮬레이션 없이 노작을 섞는다. 각 도전은 1트 최악 지출(노작가 + 최적 경로에서 가장 많이 드는 주문서 값)을 잡아 두고, 최악 지출 합계가 보유 메소 이하인 범위에서 1트 기대 이익 합계가 최대인 노작별 횟수 조합을 정확히 찾는다(`bestAttemptMix`, 분기 한정 탐색). 1트 기대 이익이 0 이하인 노작은 도전하지 않는다. 결론은 보유 + 기대 이익 합계 − 목표 구매가를 바로 구매(보유 − 구매가)와 비교한다.
- 강화 지도 (2026-10-09 Claude, 사용자 요청): 매 단계 최적 행동은 현재 공격력과 남은 횟수로만 정해지므로 추천 조합 노작들의 경로를 지도 하나로 합친다(`enhancementPolicyMap`). 위는 남은 횟수 열, 아래는 공격력 노드(추천 행동·기대값)이고 성공은 실선, 실패는 점선으로 잇는다. 노드를 고르면 10%·60%·지금 판매의 기대값과 판매 대비 변동액, 성공·실패 다음 상태를 보여준다. 기대값 = 그 행동부터 추천대로 끝까지 했을 때 평균 판매액 − 앞으로 바를 주문서 값 평균. 조합이 비면 1트 기대 이익 1위 노작의 지도를 보여준다.

- 같은 상태 비교 (2026-10-08 Claude, 사용자 아이디어): 주문서를 바른 뒤 공격력과 남은 횟수가 같으면 그 뒤 결과는 같다(예: 공53+10% 성공 = 공56+60% 성공 = 공58·남은 6회). STEP 2-1에서 입력한 노작으로 1장·2장 뒤 같은 상태가 되는 경로를 비교한다. 10%를 먼저 바르고, 중간에 실패하면 남은 주문서는 바르지 않고 상점가로 판다. 평균 제작 비용 = (노작가 + 평균 주문서 지출 − 실패작 상점 회수액) ÷ 전부 성공할 확률, 메소 단위 올림. 결론 계산과 별개인 참고 정보다. 실패작 상점가 회수·2장까지·STEP 2 아래 배치는 사용자 미답변으로 Claude 추천안을 적용했다.
- 계산 근거 표시: 결과 화면은 결론(보유 − 구매가, 평균 최종 − 구매가), 노작별 1회 평균 지출·결과별 확률×판매가 표·1회 기대 이익·보유 메소 반복(이론값과 모의 실행 평균), 포기 구간 추정가 식을 숫자로 보여준다.

- 2026-10-09 (Claude, 사용자 요청) 강화 지도는 공격력 줄 × 남은 횟수 열 보드다. 같은 공격력은 같은 높이에 두고, 칸에는 행동 구슬과 1트당 도달 확률만 표시하며 기대값은 칸을 고르면 상세에서 본다. 도달 확률은 추천 조합의 노작별 도전 횟수로 가중한 평균이고, 선 굵기·진하기를 그 경로를 지날 확률에 비례시킨다.
- 2026-10-09 (Claude, 사용자 요청) 같은 상태 비교는 묶음(1장 뒤·2장 뒤)마다 "가장 싼 경로가 두 번째 경로보다 아끼는 금액"이 큰 순서로 가로 스크롤한다. 1~3위는 금·은·동 메달로 강조하고, 넓은 화면에서 3개가 한 번에 보인다(카드 최소 폭 250px). 정렬 기준(절약액)은 Claude가 정했다.
