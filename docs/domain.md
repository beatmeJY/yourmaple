## 메이커 계산 (`#/maker`, `js/pages/maker.js`, `js/maker-calc.js`, `sql/027_maker.sql`)

탭 3개를 버튼으로 전환한다: **보석 제작**, **리버스 제작**, **장비 옵션 부여**. 리버스·장비 옵션 부여 구현은 `js/pages/maker.js`에 있다(2026-10-02 Codex [문서]). 타임리스는 사용자 자료 반영이 남아 있다는 기존 인계 기록이며 현재 완료 여부는 별도 확인이 필요하다 [추정].

- 대상 12종: 보석 8(다이아몬드, 가넷, 자수정, 아쿠아마린, 오팔, 사파이어, 토파즈, 에메랄드), 크리스탈 4(힘·민첩성·행운·지혜).
- 이미지: `img/maker/{itemId}-{stage}.png`, stage는 `ore | normal | low | mid | high`. `opal-high.png`(상급 오팔)는 현재 존재한다(2026-10-02 Codex [실측]). 이미지가 없으면 자동으로 숨긴다.
- 시세 표 `maker_gem_prices(item, tier, price, created_at)`: tier는 `ore | low | mid | high`이고 경매장 실거래가를 기록한다. 같은 아이템 시세는 계정 전체에서 공유한다. 바꿀 때마다 한 줄씩 쌓인다.
- **고정 제련비(절대 변하지 않음):** 원석 10개 → 일반 1개(조합), 일반→하급 11만, 하급 10개→중급 33만, 중급 10개→상급 55만.
- **원석 10개 → 일반 1개 조합 비용:** 가넷·자수정·아쿠아마린·에메랄드·오팔·사파이어·토파즈는 450메소, 다이아몬드는 950메소, 흑수정은 2,900메소, 힘·민첩성·행운·지혜 크리스탈류는 4,500메소다. 흑수정은 현재 메이커 대상 목록에는 없지만 향후 추가할 때 이 비용을 사용한다.
- **확률(최신 버전 대략값):**
  - 일반 제련 결과: 보석은 하급 75% · 중급 22% · 상급 3%, 크리스탈은 하급 75% · 중급 24% · 상급 1%.
  - 하급 10개→중급 성공 50%, 실패하면 하급 1개만 사라진다.
  - 중급 10개→상급 성공 25%, 실패하면 중급 1개만 사라진다.
- **등급별 적정가 계산(`tierPrices`)**: 일반 제련 100회의 총비용을 하급·중급·상급 결과물에 배분하고 승급 손익분기 관계를 함께 푼다.
  - 일반 제련 1회 비용 `C = 원석×10 + 아이템별 일반 조합비 + 11만`.
  - 중급 `M = 11×하급 L + 66만`(하급→중급 성공률 50%와 평균 실패 1회 반영).
  - 상급 `H = 13×중급 M + 220만`(중급→상급 성공률 25%와 실패 소모 반영).
  - 보석은 `100C = 75L + 22M + 3H`, 크리스탈은 `100C = 75L + 24M + H`를 만족하도록 계산한다.
  - 연립식에서 하급 가치가 0 이하이면 하급 가격과 재고는 의미 없는 것으로 표시한다. 이때 하급은 비용 배분에서 제외하고 보석은 `100C = 22M + 3H`, 크리스탈은 `100C = 24M + H`로 중급·상급 가격을 다시 계산한다.
- **상급을 얻는 세 가지 방법(`highRoutes`)**: 원석부터 제련 / 중급 사서 가공(중급 × 13개 + 220만, 성공 25% 기준 평균) / 상급 바로 구매. 가장 싼 쪽에 "최저" 배지를 붙인다.
- **중급 기준선(`midBreakEven`)**: (원석부터 제련과 상급 바로 구매 중 싼 쪽 − 220만) ÷ 13. 중급 실거래가가 이보다 싸면 사서 가공하는 게 이득이다.
  - 배경: 중급으로 상급을 만드는 성공률이 낮고 일반 제련 중에 중급이 얻어걸리기 때문에, 경매장 중급은 제작 원가보다 싸게 거래된다. 원석이 비쌀수록 중급을 사서 가공하는 쪽이 유리해진다.
- **하급 기준선(`lowBreakEven`)**: 원석부터 제련한 중급 적정가와 중급 직접구매가 중 싼 값에서 평균 제련비를 빼고 평균 하급 소모량으로 나눈다. 정확한 정수식은 `(중급 비용 − 66만) ÷ 11`이다. 하급 실거래가가 이 값 이하이면 하급을 사서 중급으로 제련하는 게 이득이다. 결과가 0 이하면 하급 구매와 재고는 의미 없는 것으로 표시한다.
- **실거래가 제작 손익(`marketCraftProfits`)**: 카드마다 일반 제련 1회 기대 손익, 하급 구매→중급 1개 평균 손익, 중급 구매→상급 1개 평균 손익을 보여준다. 일반 제련은 하급·중급·상급의 `실거래가×등장 확률` 기여액과 합계도 보여주며, 한 번에 모두 나오는 금액이 아니라 반복 제련 시 1회 평균임을 명시한다. 각 구간에 필요한 실거래가가 없으면 필요한 시세를 안내한다. 판매 수수료는 반영하지 않는다.
- 카드에서 하급·중급·상급을 누르면 계산 과정·확률 막대·비교가 애니메이션과 함께 펼쳐진다(한 카드에 하나씩).

### 리버스 제작

- 리버스 공격력별 기준 판매가는 숫자 아래에 억·만 단위 한글 금액을 함께 표시한다. 기존 priceReading을 재사용하고 금액 계산에는 BigInt를 유지한다.

- 촉진제를 사용했을 때 결과 확률은 정옵(0) 54.09%, +1 15.84%, +2 10.89%, +3 5.76%, +4 2.43%, +5 0.99%, 파괴 10%다. 합계는 100%이며 파괴를 제외한 완성 성공률은 90%다.
- 제작 재료는 오리할콘 5개, 하급 몬스터 결정 B 20개, 하급 몬스터 결정 A 14개, 시간조각 45개, 상급 보석·크리스탈 3개다. 기본 제작비는 693,000메소이고 상급 보석·크리스탈은 1개당 567,000메소가 추가된다. 촉진제를 사용하면 315,000메소가 추가된다.
- 상급 보석·크리스탈 3개는 버튼형 슬롯에서 각각 선택한다. 보석 제작 탭에 기록한 해당 아이템의 최신 상급 실거래가를 자동으로 사용하고, 시세가 없으면 슬롯의 시세 입력 버튼으로 기존 시세 기록 팝업을 연다. 같은 종류의 재료는 두 슬롯에 중복 선택할 수 없으며, 이미 선택한 재료를 다른 슬롯에서 고르면 기존 슬롯에서 새 슬롯으로 옮긴다. 촉진제 사용 여부를 켜고 끌 수 있으며, 사용할 때는 파괴 후 재제작까지 포함한 완성품 1개당 평균 투입비를 함께 표시한다.
- 리버스 제작의 상급 보석 슬롯은 장비 옵션 부여의 보석 선택 카드와 같은 제목·선택 버튼·시세 표시 구조와 스타일을 사용한다.
- 정옵 공격력을 입력하면 정옵부터 +5까지 실제 공격력을 자동으로 표시하고 각 공격력의 실거래가를 입력받는다. 제작 1회 기대 판매가는 각 실거래가에 해당 확률을 곱해 합산하며 파괴 10%는 판매가 0메소로 포함한다. 재료 시세가 모두 있으면 기대 판매가와 1회 제작비를 비교한 기대 이익·손해도 표시한다.
- 각 목표 옵션별로 `평균 시도 횟수 = 1/목표 확률`, 다른 결과의 평균 개수는 `다른 결과 확률/목표 확률`로 계산한다. 총제작비에서 다른 완성품의 예상 판매액을 빼 목표 옵션의 순제작비를 구하고, 목표 옵션 실거래가와 비교해 이익·손해를 표시한다. 파괴는 평균 횟수에는 포함하지만 판매액은 0메소다.
- 공격력별 적정 판매가는 사용자가 입력하는 값이 아니다. `101회 총 제작비 ÷ 6 ÷ 101회 동안 해당 옵션이 나오는 예상 개수`로 자동 계산해 정옵부터 +5까지 먼저 보여준다. 이는 `1회 제작비 ÷ 6 ÷ 해당 옵션 확률`과 같다. 여섯 옵션이 전체 제작비의 1/6씩 회수하도록 배분하며 전체 결과물의 예상 판매액 합계가 제작비와 일치해야 한다. 파괴 10%는 비용에 포함하되 판매 수익은 0이다. 이 값은 비용 배분 기준이며 시장 가격 예측이 아니다. 실거래가는 자동 적정가와 손익을 비교하기 위한 선택 입력값으로만 받는다.
- 메이커 상단의 보석 제작·리버스 제작·장비 옵션 부여는 게임 메뉴형 탭이며, 선택한 탭의 패널 하나만 표시한다. `hidden` 패널은 CSS에서 반드시 `display:none`으로 유지한다.

## 링크 패널 (`js/link-panel.js`)

- 사이드바 "링크"는 페이지를 이동하지 않는다. 아래에서 패널이 올라와 저장된 링크를 파비콘과 함께 보여주고, 링크를 누르면 패널이 닫히며 새 탭으로 열린다.

## 강화 계산 (`#/enhance`, `js/pages/enhance.js`, `js/enhance-calc.js`)

- 첫 구현 범위는 무기 강화다. 일반 무기는 업그레이드 가능 횟수 7회, 발록의 무기는 8회다.
- 10% 주문서는 성공 시 공격력 +5, 60% 주문서는 성공 시 공격력 +2다. 성공과 실패 모두 업그레이드 가능 횟수를 1회 소모한다.
- 목표 공격력은 두지 않는다. 사용자는 상점 판매가, 두 주문서의 시세, 공격력별 노작 무기 구매가, 완성 공격력별 경매장 시세를 입력한다. 노작 공격력은 기준값의 -5부터 +5까지 한 번에 만들거나 직접 행을 추가한다.
- 완성 공격력의 경매장 시세가 비어 있으면 상점 판매가로 회수한다. 업그레이드 횟수가 남은 상태에서 강화를 중단할 때도 상점 판매가를 사용한다.
- 현재 공격력과 남은 횟수마다 `10% 사용`, `60% 사용`, `즉시 상점 판매`의 기대가치를 비교하는 동적 계획법으로 최적 행동을 고른다. 목표 도달 여부와 관계없이 계속할 가치가 있으면 강화하고, 기대가치가 상점가보다 낮거나 같으면 즉시 중단한다.
- 노작 무기별 기대 이익·수익률·평균 주문서 사용량·중도 판매 확률과 상태별 행동을 계산하고, 기대 이익 및 수익률 기준 1~3위를 각각 보여준다.
- 강화 계산 설정은 `enhance_profiles`에 사용자별 아이템 프로필로 저장한다. 현재 화면 제한은 `MAX_ENHANCE_PROFILES = 5`이며 DB에는 개수 상한을 두지 않아 이후 쉽게 늘리거나 줄인다. 프로필에는 무기 종류·상점가·주문서 시세·노작 시세·완성품 시세를 JSON 문자열 금액으로 함께 저장한다.
- 계산은 `js/enhance-calc.js`에 두고 `node js/enhance-calc.check.mjs`로 검증한다. 금액은 BigInt, 확률은 분모가 `100^시도 횟수`인 BigInt 정수로 계산한다.

## 장비 옵션 부여

- 장비 옵션 부여 탭은 보석·크리스탈을 1~3개 선택해 총 제작비를 계산한다. 서로 다른 재료의 등급 혼합은 허용하지만 같은 종류의 보석·크리스탈은 등급이 달라도 중복 선택할 수 없다. 이미 선택한 재료를 다른 슬롯에서 고르면 기존 등급을 유지한 채 새 슬롯으로 옮긴다.
- 장비 옵션 부여의 새 보석 슬롯과 비운 슬롯은 상급을 기본 등급으로 선택한다.
- 기본 메이커 비용은 275만 메소다. 보석 1개당 등급별 추가 비용은 하급 75만, 중급 150만, 상급 225만 메소다.
- 총 제작비는 `기본 메이커 비용 + 선택한 보석 실거래가 합계 + 등급별 추가 비용 합계`다.
- 보석 제작 탭에 기록한 해당 등급의 최신 실거래가를 사용한다. 시세가 없으면 기존 시세 기록 팝업을 바로 열 수 있는 버튼을 표시한다.
- 메이커 페이지 제목 영역의 오른쪽에는 작은 공용 시세 보관함을 항상 펼쳐 두고, 제목의 기준선을 보관함 아래쪽에 맞춘다. 제목은 필요한 너비만 사용하고, 시세 보관함의 실제 너비에 따라 보석 카드를 2열·3열·4열·6열로 나누어 행과 카드 폭을 안정적으로 유지한다. 각 카드는 첫 줄에 일반 이미지·이름·원석 시세를 두고, 둘째 줄에 하급·중급·상급 시세를 한 줄로 표시한다. 금액은 만·억 단위로 줄여 가로 스크롤 없이 보여준다. 가격 칸을 누르면 기존 시세 기록 팝업이 열리며 저장한 최신 시세는 세 계산 탭에 즉시 함께 반영한다.
- 보석 카드의 이름 영역을 누르거나 리버스·장비 옵션 부여에서 보석을 선택하면 해당 보석의 원석·하급·중급·상급만 모은 빠른 시세 편집 패널을 연다. 패널은 배경을 어둡게 덮지 않고 화면 최상단의 작은 영역으로 내려오며, PC에서는 링크 패널처럼 사이드바를 제외한 본문 전체 폭을 사용하고 모바일에서는 화면 전체 폭을 사용한다. 각 등급을 바로 저장할 수 있고, 패널 바깥이나 닫기·Esc를 누르면 다시 위로 접힌다.
