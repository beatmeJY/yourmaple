# 다크 글래스 리디자인 진행표

- 디자인 원본: 저장소 안 `yourmaple_design_2/`(최신, 7개 분류·무릉 한 페이지·거래 장부 포함)와 이전판 `yourmaple_design/`. 인계 문서는 각 폴더 `README.md`, 시안은 `MapleApp.dc.html`. **커밋하지 않고 로컬에서만 관리**한다(`.git/info/exclude`). 시안은 참고용이며 계산 로직·Supabase 데이터는 기존 것을 쓴다.
- 화면 하나씩 바꾸고 PC·모바일을 확인한 뒤 사용자 확인을 받고 다음으로 넘어간다. 배포는 여러 단계를 묶어서 한다.

## 결정 (2026-10-10 사용자) [진술]

- 다크 전용. 라이트/다크 전환을 없앴다.
- 강화 계산은 지금 기능(보유 메소 비교, 강화 지도, 같은 상태 비교)을 유지하고 스타일만 입힌다. 강화·메이커·혼돈의 주문서 시뮬레이터는 나중에 추가한다.
- 무릉은 허리띠 시세와 층별 기록을 합친 한 페이지 기준이다. 거래는 `yourmaple_design_2`의 "거래(180) › 거래 장부" 분류를 따른다.
- 배포는 묶어서 한다.

## 결정 2 (2026-10-10 사용자, 4단계 중간 결정 목록 답변) [진술]

- 메모 색·고정·자동 저장(SQL)은 보류, 지금처럼 분류별 자동 색 + 저장 버튼.
- 숙제 체크리스트·직업 가이드는 보류(A). 숙제 초기화는 세 방식: 00시(무릉), 입장 뒤 24시간(파풀라투스·차원의 균열 조각), 7일(피아누스). 피아누스는 7일이 맞다(시안의 "하루 1회"는 쓰지 않음). 직업 가이드 자료는 사용자가 나중에 준다.
- 사냥터 추천은 사용자의 사냥 기록 EXP/h로 순위를 매긴다.
- 대표 캐릭터는 DB에 저장해 모든 기기에서 같게. 바꾸는 UI는 전역(헤더 프로필 얼굴)에 둔다.
- 캐릭터에 현재 경험치 입력을 추가한다. 사냥 기록이 있으면 가장 좋은 기록(또는 사용자가 고른 대표 사냥터) 기준 "다음 레벨까지 약 N시간"을 보여 준다.
- 캐릭터 상세는 즉시 저장(레벨·경험치·보스·퀘스트 제외·메모). 이름·직업·계정·얼굴은 저장 버튼 유지(사용자 미답변, 에이전트 제안 기본값).
- 효과음은 처음부터 켜짐. 헤더에 기능 검색과 프로필 얼굴을 넣는다.
- 배포 때 JS·CSS 주소에 버전을 붙인다(주소창에는 안 붙음). 지금까지 작업을 먼저 커밋·배포한다. 모바일 흐림 성능은 6단계에서 실제 폰으로 보고 정한다.
